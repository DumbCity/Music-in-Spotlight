# Music-in-Spotlight
  Music Feature in Spotlight with sound effects for a full immersive experience

  Super Mario 3D World Stage Editor

———————————————————————————————————————

Spotlight Music

 Backround Music
  
  - Put .mp3 or .wav files right in this folder (not in a subfolder).
  - They show up in the Music menu's song drop-down automatically.
  - If you add songs while Spotlight is open, just set the folder again (or restart) to refresh.
  - Play / Stop and Loop do what they say. Volume is the top slider.

 Sound Effects
  
  - Put .mp3 or .wav files in the 'soundeffects' subfolder.
  - The FILE NAME decides when it plays. Example: soundeffects\place.mp3 plays when you place an object.
  - Missing file = silence for that action. You only need the ones you want.
  - If both place.mp3 and place.wav exist, mp3 wins.
  - Short clips (under ~2 seconds) work best.

 Sound Effect Names

  addobject.mp3 / .wav      Add Object dialog is opened (Shift+A)
  addzone.mp3 / .wav        Add Zone is used
  delete.mp3 / .wav         Selected things are deleted

  paste.mp3 / .wav          Paste

  undo.mp3 / .wav           Undo
  redo.mp3 / .wav           Redo                                                                 
  save.mp3 / .wav           Save
  saveas.mp3 / .wav         Save As
  open.mp3 / .wav           A level/zone is opened
  selectall.mp3 / .wav      Select All
  deselectall.mp3 / .wav    Deselect All
  grow.mp3 / .wav           Grow Selection
